# Featured Systems

## Tiannara

### Autonomous Cognitive & Discovery Platform

Tiannara is my primary long-term systems engineering project.

It explores an architecture for intelligent software capable of combining:

- Discovery
- Memory
- Cognition
- Hypothesis generation
- Experimentation
- Forecasting
- Decision intelligence
- Safety constraints
- Autonomous software engineering
- Evidence and measurement

The system incorporates multiple engineering layers and technologies, including software orchestration, memory infrastructure, AI components, distributed messaging, databases, runtime supervision, and verification systems.

**Status:** Active development  
**Core repository:** Private

### Research tracks within Tiannara

**ASC — Autonomous Software Civilization**

Research into increasingly autonomous software engineering systems, capability auditing, runtime resilience, executive memory, autonomous code quality, and certification.

**EFDI — Epistemic Forecasting & Decision Intelligence**

Research into forecasting, calibration, decision intelligence, uncertainty, evidence, and bounded certification.

**Measurement Integrity**

Engineering work focused on ensuring that system measurements, benchmarks, tests, and certification claims remain tied to observable evidence.
